The puzzle

Plan the next shipment before you tap.

The core is easy to read and rewards deliberate choices: visible queues, ordered truck needs, limited temporary space, and cargo that becomes more interesting as the warehouse opens up.

Read the lanes

Only the front cargo in each warehouse lane is available, while buried freight remains visible so you can plan what is coming.

Follow the manifests

Two active trucks normally wait at the top with visible ordered manifests. Load what each truck needs next and react as completed trucks depart.

Use staging wisely

Limited shared staging gives you breathing room, but careless moves can box you in. The best route is not always the first obvious tap.

More than a sorting board

Curio Cargo is built around recognizable freight rather than abstract tokens. Completing contracts grows the larger Curio Cargo Co. fantasy through a persistent warehouse, a Cargo Catalog, discoveries, and cosmetic customization.

The goal is a broad casual puzzle experience: easy enough to keep momentum, thoughtful enough to feel like a game, and occasionally challenging enough to create memorable wins.
