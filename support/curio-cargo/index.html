Curio Cargo support

Need help moving freight?

Curio Cargo is still in development. This page is ready to become the permanent support destination when the game reaches Google Play.

Contact support

Email support@hunnerbunnergames.com with “Curio Cargo” in the subject line.

For technical issues, it helps to include:

  • device make and model;
  • Android version;
  • what you were doing when the issue occurred;
  • whether the issue happens every time;
  • a screenshot when useful.

Current status

Curio Cargo has not launched publicly yet, so there are no published known issues or release notes on this page.

Once the game is available, common troubleshooting information will live here so support stays easy to find without requiring a separate account or ticket system.
